# Security policy

## Reporting a vulnerability

Please **don't open a public issue** for security problems (for example, a way the loader could
be abused to run untrusted code, or a release file that doesn't match its published checksum).

Report it privately through GitHub instead: on the repository page, open **Security → Report a
vulnerability** ([private advisory form](https://github.com/cherrymcgerry/acr-rewind/security/advisories/new)).
Include what you found, the mod version and game build, and how to reproduce it.

## Supported versions

Only the latest release gets fixes. ACR Rewind is a hobby project, so there is no guaranteed
response time, but reports are taken seriously.
